# Wanderlust — Travel & Tourism Website

A modern, responsive travel and tourism website built with **HTML, CSS and vanilla JavaScript**.

## Files
- `index.html` — complete website structure
- `style.css` — responsive styling and animations
- `script.js` — navigation, package filters, testimonial slider, contact form and back-to-top interaction

## How to run
1. Download or clone the project.
2. Keep all three files in the same folder.
3. Open `index.html` in Chrome, Edge or Firefox.

No build tools or npm packages are required.

## Features
- Responsive desktop/tablet/mobile layout
- Hero section with travel call-to-action
- Destination cards
- Filterable travel packages
- Testimonial carousel
- Travel gallery
- Contact/enquiry form with client-side validation
- Mobile navigation
- Smooth scrolling
- Back-to-top button
- Modern typography and hover animations

## Note
The photos are loaded from Unsplash URLs, so an internet connection is required for the online images.
